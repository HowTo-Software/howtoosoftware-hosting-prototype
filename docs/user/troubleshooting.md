# User troubleshooting

> **Status:** Checked against the local code; team review pending
>
> **Owner:** HTS / HowToSoftware maintainers
>
> **Last updated:** 2026-10-05

| Problem | Action |
| --- | --- |
| Payment button unavailable | Read the message and use the contact link; installation may lack integration settings |
| Promotion code rejected | Check code, period, and stated rules; do not assume a discount until Checkout accepts it |
| Payment completed, delivery ongoing | Follow status; if it persists, privately contact HTS with reference and timestamp |
| Local login rejects credentials | Use the external panel link; local login is a demonstration |
| Estimate does not open | Check email application setup; the action prepares a draft |
| Language is not remembered | Check cookie permission; selection depends on a cookie |
| Wordmark animation absent | Reduced motion or unavailable WebGL may apply; static content is expected |
| Interactive controls disconnect | Reload and check connection; report route/browser if repeated |
| Page shows previous route's text | Reload and report navigation sequence, language, and theme |
| Clicking trial did not create it | Confirm the email first; wait for installation and the ready email. If unavailable, HTS must configure the integration |
| Trial access missing on another device | Use the trial page's email recovery; it restores access without creating a second trial |
| Trial suspended | The 24 hours ended. Choose a plan within the 3-day save retention window |

Never send passwords, card details, keys, or environment screenshots to support. Purchase references and personal data belong in private channels.

For reproducible bugs, use the [bug reporting guide](../phase-4-testing/bug-report-template.md). For server/integration diagnosis, use the [operations runbook](../phase-6-operations/runbook.md).
