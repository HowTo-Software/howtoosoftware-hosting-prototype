## Find and choose hosting

Explore the homepage offer and open the game catalog. Project Zomboid has available plans; Minecraft is marked as planned. Compare memory, CPU, disk, and backups on the product page.

Choose monthly, quarterly, or annual billing and check the period total in review. A monthly equivalent may be shown for comparison. Amounts use the displayed currency; Portuguese language does not convert them into Brazilian reais.

## Review and pay

Check game, plan, resources, and period before continuing. Enter a promotion code if available; its validity is checked when starting payment. The button opens Stripe, where card details are entered.

If payment is unavailable in the current installation, review explains this and provides contact. A click or opening the success page does not confirm a charge.

After Checkout, the site tracks confirmation and provisioning. The server is released only after the backend accepts payment and installation completes according to the panel response.

## Access the panel

The panel link opens the external `panel.howto.software` address. That application has its own login. Local site login/registration pages are demonstrations and do not create an HTS identity.

Panel links open the external Pterodactyl application. The homepage no longer includes simulated server charts.

## Customize reading

The header offers light/dark themes and EN/PT-BR. A cookie remembers language; browser preference helps select it on the first visit. Spanish is not available in this project yet.

The site respects reduced-motion preferences. Without WebGL or scripts, branding and content have static presentation.

## Request a special configuration

The custom section lets you adjust resources and view an estimate. Its contact action prepares an email; review text/recipient and send through your email application. It does not create a subscription or reserve capacity.

The trial action opens `/trial`. Choose Project Zomboid or Minecraft; for Minecraft choose an available Java/Bedrock profile, variant and version. Confirm your email before the account and server are created. The 24-hour clock starts after installation completes. The server is then suspended and the save retained for 3 additional days. Purchase an available plan during that period to continue on the same server. One trial is allowed per account across games. Use email access recovery on another device. Unconfigured integrations are shown as unavailable.
