# Control panel screenshots

Real captures of the HTS control panel (the Pterodactyl-based panel at panel.howto.software),
supplied by the company. Nothing here is a mock-up.

| File | What it shows | Used by |
|---|---|---|
| `workshop-manager.webp` | The Project Zomboid Workshop Manager: server header, sidebar, search row | `/game-hosting/project-zomboid` intro |

`workshop-manager` is cropped to the panel's own chrome. The Workshop search results below the
search row carry thumbnails drawn by third-party mod authors, so they were left out rather than
republished here.

Replace a file with a newer capture of the same view and nothing else needs to change.
